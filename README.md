# Index Page

Este repositorio contiene una página de inicio sencilla con:

- `index.html` para la estructura del sitio.
- `styles.css` para los estilos.
- `images/` para los recursos gráficos.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Modifica `styles.css` para actualizar el diseño.
3. Añade imágenes en la carpeta `images/` si lo necesitas.

## Notas

Este proyecto parece ser una página estática básica. Si agregas herramientas de construcción o dependencias, recuerda actualizar `.gitignore` según sea necesario.
